## 性能实测

运行 `node scripts/benchmark.mjs` 生成 `artifacts/benchmark.json`。这是高密度 Markdown 数据集的 Node/Electron 外部基准，不是所有文档的保证。最新构建的单样本结果为：约 100 KiB 解析 344 ms、HTML 99 ms；约 1 MiB 解析 1.84 s、HTML 0.56 s；约 5 MiB 解析 8.23 s、HTML 2.14 s。索引查询 p95 约为 0.56 / 2.13 / 10.09 ms。`benchmark.json` 本次为 `MARKZ_BENCH_SAMPLES=1` 的快速复测，正式比较应使用默认 5 个样本。

大文档编译已经移入 Worker，且无自定义语法插件时会尝试在安全的顶层标题处分段；引用定义、BOM 或无法确认边界时回退完整 unified。5 MiB 高密度数据仍未达到需求建议的 4 秒级载入预算，后续需要增量解析或更细的缓存策略，不能将该预算写成已通过。

## 打包限制

0.1.0 初次交付时没有生成 NSIS 安装器。此状态已在 0.1.1 修复交付中解决：利用现有缓存成功生成 `release/0.1.1/Markz-0.1.1-win-x64.exe`，同时生成了更新后的便携版。用户无需另外下载 NSIS 工具。

第三方依赖许可证清单见 `artifacts/dependency-licenses.json`。项目尚未公开发布 npm 或安装包渠道。
