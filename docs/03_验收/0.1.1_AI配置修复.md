## 用户确认的需求

模型能力仅展示文本和图像。文本固定开启，不可关闭；图像由用户根据模型的实际能力勾选，默认关闭。流式、工具调用、结构化输出、推理不再展示为模型能力开关，内部协议兼容配置保留。

图像能力标记按模型 ID 独立保存；切换模型或刷新列表不会覆盖其他模型设置。旧配置加载时自动迁移，不要求用户重建服务。图像标记本身不上传图片，本次没有新增图片附件传输流程。

## 404 的原因与修复

用户配置的 `https://api.deepseek.com/anthropic` 符合 DeepSeek 官方文档。旧实现错误地将模型列表和消息请求都拼接到该前缀后：

| 操作 | 旧请求 | 修复后的请求 | 鉴权 |
| --- | --- | --- | --- |
| 获取模型 | `GET /anthropic/models` | `GET https://api.deepseek.com/models` | Bearer |
| 消息生成 | `POST /anthropic/messages` | `POST https://api.deepseek.com/anthropic/v1/messages` | x-api-key |

该适配仅匹配 `api.deepseek.com` 精确域名，模型发现仍在同源完成；其他服务保留其自定义网关前缀。完整 `/anthropic/v1/messages` 地址和 `/anthropic/v1` Base URL 同样可用，不重复添加版本。

模型列表返回 404 或 405 时映射为 `MODEL_LIST_UNAVAILABLE`，用中文/英文提示手动输入模型 ID 并测试连接。界面不显示 Electron `Error invoking remote method` 包装文本。列表接口缺失不再阻止配置和生成测试。

官方公开依据：

- [DeepSeek Anthropic API](https://api-docs.deepseek.com/guides/anthropic_api)
- [DeepSeek Models API](https://api-docs.deepseek.com/api/list-models)
- [Anthropic Python SDK 消息路径](https://github.com/anthropics/anthropic-sdk-python/blob/main/src/anthropic/resources/messages/messages.py)
